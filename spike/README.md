# Step 16 recorder spike (Phase A)

Quarantined experiments E1–E6 for desktop capture feasibility. **Not shipped** in the
ordine wheel/sdist. Install spike-only deps locally:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
```

Run from repo root or this directory with `DISPLAY` set. See `docs/recorder-spike.md` for results.
